#+title: Roadmap de Refractómetro

* v3 — Objetivo del producto

El refractómetro debe ayudar a encontrar el pico asociado al cambio de índice de
refracción de una sustancia. El flujo principal de laboratorio será adquirir
muchos barridos, reducir el ruido mediante un promedio reproducible y analizar
el pico de la curva promedio. Las calibraciones seguirán el mismo flujo, pero
se adquirirán sin muestra y producirán una referencia promedio.

La interfaz de v3 debe guiar este flujo de laboratorio explícitamente. La
visibilidad de una curva sirve para visualizarla y no debe confundirse con la
selección de datos para un análisis.

* Convenciones para v3

- Los barridos individuales son datos crudos y no deben perderse cuando se  calcula un promedio.
- Todo resultado derivado debe guardar sus fuentes, parámetros y versión del  protocolo utilizado.
- La visibilidad de una curva es una decisión de presentación; la selección  para adquirir, promediar o corregir es una decisión analítica explícita.
- Las corridas fallidas, canceladas o atípicas se conservan para auditoría,  pero no participan silenciosamente en un resultado.
- Las calibraciones se producen mediante el mismo flujo de repetición y  promedio que las muestras, usando un protocolo sin muestra.
